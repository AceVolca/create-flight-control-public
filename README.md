# Create: Flight Control — Issue Tracker

This repository is the public issue tracker for **Create: Flight Control**.

Please use the [Issues](../../issues) page to report bugs or request new features.

## Reporting a Bug

Before opening a new issue, please:

* Search existing issues to make sure the problem has not already been reported.
* Use the **Bug Report** template and provide all requested information.
* Include your Minecraft version, mod version, mod loader and other relevant mods.
* Attach `latest.log` and crash reports when applicable.
* Provide clear steps to reproduce the issue whenever possible.

## Feature Requests

Feature requests and suggestions are also welcome. Please use the **Feature Request** template when opening an issue.
